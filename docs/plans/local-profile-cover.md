# 本地自定义卡面

2026-11-24 · 步骤 1～3 已在本地分支完成；实施及验收见 [dev.20](../dev-log/v1.0-dev.20.md#本地自定义卡面)。用户已选定图片只保存在本地、仅本人可见。将来开放访客主页时，访客看到主页主人选定且有资格使用的官方卡面。以下操作名称、图片预算和交付拆分为首版建议。

## 两个选择各自保存

例如小林已佩戴「黄铜星盘」，又在电脑上选了一张猫的照片。电脑上的本人个人页显示猫；手机登录同一账号仍显示星盘。小林可以在电脑上把官方款换成已解锁的「末班信号」，电脑仍显示猫，手机随账号同步为末班信号。将来朋友访问小林的主页也看到末班信号。在电脑上切换到官方卡面后，立即显示当前的末班信号。

| 访问场景 | 显示依据 |
| --- | --- |
| 已认证账号进入本人空间，当前浏览器有已启用且能读取的本地图片 | 使用当前账号的本地成图，沿用现有头像叠放和卡面高度 |
| 本地图片未启用、未找到或读取失败 | 使用服务端确认的官方佩戴；首次打开尚无可用官方结果时显示窗边初晴 |
| 其他设备、浏览器配置或账号 | 在各自环境独立取图，首次使用显示本账号官方款 |
| 未来的访客主页，包括本人打开「访客视角」 | 只由公开资料中的有效官方款式编号渲染。该页面不调用本地图片读取逻辑 |

官方解锁条件、购买及佩戴继续由服务端判定。复用现有官方佩戴字段即可表达未来的访客选择。当前三张官方图仍随网站分发。自定义图交给浏览器处理，选择、预览、保存和删除的图片数据均留在本机，因此首版无需图片托管、审核队列或新的后端接口。[官方卡面规则](profile-card-backgrounds.md#解锁与佩戴方案)

## 个人页操作

沿用资料区「更换卡面」和现有选择弹窗。保留三张官方缩略图，在其下增设「自定义卡面」一栏和文件入口。首次选图前明确提示图片仅在当前浏览器中对本人可见，清除网站数据后需重新选择。已有本地图片时同时标明「当前浏览器显示」与「账号官方卡面」，避免两张图都写“使用中”。

| 用户操作 | 成功后的效果 |
| --- | --- |
| 选图、调整、取消 | 在弹窗预览桌面、手机取景及头像遮挡。取消或 Esc 丢弃本轮草稿并回到原显示 |
| 保存并使用本地图片 | 本账号在这个浏览器保留一套成图。只有保存成功才替换原图并启用 |
| 更换官方款 | 复用购买确认与佩戴流程。启用本地图片时按钮写「设为账号官方卡面」，成功后只更新官方选择，购买本身仍不自动佩戴 |
| 切换到官方卡面／使用本地图片 | 切换本地启用状态。停用后保留成图，可一键恢复 |
| 删除本地图片 | 明确确认，仅清除当前浏览器内本账号的这套图片与启用状态，立即回到官方款 |

建议所有可正常使用个人资料的账号均可免费使用一个本地卡面位。首次改密、身份尚未确认或会话失效时沿用个人页已有的访问限制。

## 图片与持久化

- 采用 IndexedDB（浏览器站点数据库）直接保存二进制 Blob。按应用命名数据库和记录版本，以已认证的稳定用户 ID 区分账号。每条含桌面、手机两张成图和启用状态，不保存令牌、原始文件、文件名或本机路径。不同协议、主机、端口或浏览器配置有独立存储，所以开发预览端口和正式域名的数据各自独立。
- 建议支持静态 JPEG、PNG、WebP。选图组件限制文件大小并识别真实格式、尺寸和动画，过大或不支持时给出可操作提示。首版接受 8 MiB、1600 万像素以内且最长边不超过 8192px 的源图。显示时只使用本地生成的静态位图。文件入口和拖放都走同一校验流程；首版只需文件入口。
- 在图片上分别保存桌面和手机的取景结果。提供拖动、缩放、重置，以及键盘移动操作。参考已有头像裁剪的 Pointer Events 与键盘行为，按横幅比例单独计算裁剪区域。适配现有 560px 取图断点、760px 卡高断点。首版导出桌面 2320×360、手机 1080×420 的静态 WebP，每套最多 1 MiB。显示时依窗口宽度居中适配，极窄窗口可能裁去画面边缘。[个人页](../../polyhouse-web/src/views/AccountView.vue) · [头像裁剪交互](../../polyhouse-web/src/components/AvatarUploadDialog.vue)
- 从本地原图按方向解码，重新编码两份成图并去除原始位置等元数据。原图只在编辑期间驻留内存。保存后若要重新取景，提示再次选择原文件。大图解码、内存占用和导出时间，以目标手机实测为准。
- 同一个 IndexedDB 事务保存两张图及状态；完成后再切换展示。配额不足、存储禁用、图片损坏或编码失败时保住原图及官方选择。每次显示创建临时对象 URL，在替换、取消、切账号、页面卸载时释放。数据库升级被另一标签页阻塞时给出关闭旧页并重试的提示。

## 账号、隐私和异常边界

- 仅在确认登录并进入本人页面后依账号 ID 加载。切换、登出时立即清空可见图片和草稿，使旧读取、解码或保存回调失效；事务始终绑定发起账号。普通退出保留该账号的本地保存，方便下次使用。本人成功注销时尝试清理这台设备上的记录。其他设备上的浏览器数据由用户在当地清理。
- 同账号多标签页保存或删除后可用轻量通知触发重读，只传变更信号；页面重新获得焦点时也能同步。以最后成功提交的本地事务为准。官方资格发生变化时照常刷新服务端官方选择，本地启用状态独立保留。
- 「仅自己可见」指应用只在匹配的本人页面呈现。不承诺对共用同一浏览器配置、能读取该设备站点数据的人加密。隐私浏览、浏览器自动回收或清除站点数据都可能使图片消失。用户可保留原照片以便重选。
- 卡面图片、裁剪数据和文件信息不进请求体、外链、埋点、错误日志、登录缓存或服务端备份。保留既有的正常登录、官方目录与佩戴网络请求。后续访客页单独提供公开的官方款编号，并在服务端复核可用资格；无需迁移、读取或公开已有本地图片。

## 分步实施与验收

| 步骤 | 可独立验证的交付 | 通过条件 |
| --- | --- | --- |
| 1. 本地存储与显示规则 | 账号隔离的读写、启停、删除及官方回退 | 测 A/B 两账号、刷新、登出再登录、两标签页更新与删除、切号时旧响应晚到。模拟磁盘满和写入中断，确保旧成图完好 |
| 2. 裁剪与试穿 | 选一张图，预览两种画幅，确认后才保存 | 试横图、竖图、带方向信息的手机照片、坏文件和超限图；键鼠、触屏均可选取和取消；在 320、390、559/560/561、759/760/761、1440px 核对遮挡与焦点 |
| 3. 接入选择器并联调 | 本地图片与官方佩戴能分别操作，购买与角色规则照常生效 | 用两个独立浏览器配置登录同一测试账号，一端启用私图并更换官方款，另一端仅看到新官方款；停用、恢复、删除、刷新均符合上表。检查网络请求中无用户图片或裁剪数据，复验硬币购买、等级及特权路径 |
| 4. 后续开放访客主页时 | 使用受控公开资料读取官方卡面 | A 自己看私图，B 看 A 的有效官方图。即使 B 的浏览器里曾登录过 A，也不显示 A 的本地图片。该步随访客主页另行实施 |

首版交付为步骤 1～3。实施时运行前端构建、Lint、相关测试和浏览器联调。回退前端版本后个人页恢复官方显示，已有官方购买、余额与佩戴无需修复。
