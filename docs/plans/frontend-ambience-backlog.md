本计划对外部朋友提出的一组偏二次元博客 / 个性化交互风格的前端建议进行**工程化“蒸馏”**：保留其中有辨识度、能增加网站灵气与互动乐趣的精髓，剔除会伤害工具箱可读性、首屏性能、移动端体验或触碰安全/版权红线的做法，沉淀为后续按需挑选立项的远期候选清单。

## 二、逐项“蒸馏”与分级评估

按 **产品契合度 × 实现性价比 × 工程风险** 分为 **A（最值得做）/ B（做成可选开关/彩蛋）/ C（高风险须强约束或暂缓）** 三档：

### A 档 · 最契合聚妙屋定位，建议未来优先挑着做

| 编号 | 项目 | 朋友原意 | 直接照搬的坑 | 聚妙屋“蒸馏”落地方案 | 涉及端与成本 |
| --- | --- | --- | --- | --- | --- |
| **A1** | **跟随系统的白天 / 夜晚模式** | 随系统自动切昼夜模式 | 直接用 CSS `filter: invert()` 会毁掉插画、星潮横幅与图片对比度；Element Plus 组件易出现白字白底 | 基于现有 `App.vue` 语义变量（`--ph-*` / `--st-*`）补齐一套手工校准的深海夜色令牌，叠加 Element Plus 暗色变量；提供「跟随系统（`prefers-color-scheme`）/ 浅色 / 深色」三态切换并持久化 `localStorage`；全页核对 WCAG AA `4.5:1` 对比度 | 纯前端；中等工作量、长期收益最高 |
| **A2** | **个人空间活跃热力图 + 贪吃蛇彩蛋** | 贪吃蛇热力图（类似 GitHub contribution snake） | 聚妙屋没有代码提交记录，强挂 GitHub API 会暴露外部依赖与限流问题 | 复用聚妙屋已有的**每日登录成长流水**（或后续扩展站内活跃天数），在 `AccountView`「我的成长」区展示近半年的清爽网格热力图；默认静态高可读，提供一个「放只小蛇吃格子」彩蛋按钮触发轻量 SVG/Canvas 贪吃蛇动画（服从 `prefers-reduced-motion`） | 需 1 个只读后端汇总接口（仅查本人活跃日期，低成本）+ 前端组件 |
| **A3** | **聚妙屋风格「拉绳回顶」小挂件** | 右侧「上吊小猫」回到顶部 | 原版图片素材版权不明；窄屏手机和 768px 以下容易挡住表单与列表按钮 | 保留「滚动超过 1.5 屏垂下、点击拉绳平滑回顶」的趣味机制，素材改为**原创极轻量 SVG**（例如聚妙屋「小屋挂灯」或「折纸小猫」）；仅在桌面宽屏（`>= 1180px` 且留白区充足时）显示，移动端退化为不遮内容的简洁回顶按钮或隐藏，支持键盘 `Tab` 聚焦 | 纯前端；低成本、趣味度高 |

### B 档 · 做成「默认关闭的可选外观 / 彩蛋」，绝不强加给默认工具页

| 编号 | 项目 | 朋友原意 | 直接照搬的坑 | 聚妙屋“蒸馏”落地方案 | 涉及端与成本 |
| --- | --- | --- | --- | --- | --- |
| **B1** | **可选氛围壁纸 + 轻度毛玻璃皮肤** | 底部加壁纸 + 框框全改玻璃质感 | 高饱和壁纸 + 高透明玻璃会严重削弱「妙替 / 妙压 / 星潮」的文字可读性；大面积 `backdrop-filter: blur()` 在移动端和低端机明显掉帧；外链公益图床不可控 | 与 PR #20 已落地的[个人空间卡面](profile-card-backgrounds.md)思路衔接，做成**用户主动开启的「轻玻璃氛围模式」**（默认关闭，坚守白底墨色基线）；仅使用项目自备有界 WebP 淡雅氛围底图（绝不直连外部随机图 API），仅对导航栏与外层壳体做克制毛玻璃（`rgba(255,255,255,0.85) + blur(10px)`），核心阅读与工具编辑区保持高对比实底 | 纯前端；中等成本，需严格压测滚动帧率与文字对比度 |
| **B2** | **克制的点击微动效（替代全屏鼠标特效）** | 加鼠标特效 | 全屏常驻 Canvas 拖尾、飘花或替换原生指针极度干扰文本选中、代码阅读和头像/图片拖拽裁切 | 放弃常驻鼠标拖尾和自定义指针；若要做，仅做成「外观设置里默认关闭的极轻点击涟漪 / 星点微反馈」（纯 CSS 轻量动画、触发即销毁），在 `prefers-reduced-motion` 与触摸屏下自动禁用 | 纯前端；低成本 |
| **B3** | **「小人弹珠」休闲彩蛋玩具** | 类似 `t.alcy.cc` 的 ds 小人弹珠 | 若常驻在业务页面底部或边栏弹跳，既分散注意力又长期占用主线程与电量 | 收纳为**页脚隐藏彩蛋入口或独立休闲小弹窗**；点击后才通过动态 `import()` 懒加载一个极轻的物理弹珠 / Q 版小人互动玩具（不引入重型 3D/物理大库，零首屏体积成本），随时一键关闭清空 | 纯前端（独立懒加载 chunk）；中低成本 |

## 三、明确不采纳的 4 条红线（防踩坑备忘）

1. **不直连第三方公益随机图 API 作为线上壁纸资产**（如 `t.alcy.cc` 等）：存在外链随时失效、图片内容不可控、破坏可读性与隐私日志泄露等风险；聚妙屋全部视觉素材只用受控自备静态 WebP 资源。
2. **不把工具页默认背景做成花哨壁纸 + 高透明毛玻璃**：妙替（多文件替换）、妙压（目标体积压图）和星潮（技术阅读）的核心价值是“顺手、清晰、不累眼”，氛围皮肤只能是可选开关。
3. **不对公网匿名开放免费 AI Agent**：任何触发第三方收费模型调用的入口都必须经过 `INSIDER` 权限与本地账本预算熔断保护。
4. **不在 `<= 768px` 移动端常驻大型右下角悬浮挂件**：不牺牲 320px～768px 断点的触控空间与零遮挡验收基线。

## 四、未来若启动时的推荐分期顺序

1. **第一批（全员受益、最契合产品）**：`A1 白天/夜晚模式` → `A2 个人空间成长热力图（含贪吃蛇彩蛋）` → `A3 原创拉绳回顶小挂件`。
2. **第二批（个性装扮、开关隔离）**：`B1 可选轻玻璃氛围模式` → `B2 点击微反馈开关` / `B3 懒加载小人弹珠彩蛋`。
3. **第三批（看精力与原创素材再定）**：`C1 原创轻量小屋吉祥物` + `C2 站内零成本本地向导`（收费 AI 对话仅在明确有内测需求与预算时再单独评估）。
