## 建议推进顺序与验收底线

1. **推荐先做 F1 + F3**（改动轻量、用户感知最直接，零复杂状态风险），再做 **F2**（工作台页头减重），最后推进 **F4 + F5**（大页面视觉拉齐与全站令牌/断点总检）。
2. 每个子闭环独立开分支、独立验证 `npm run build`、`npm run lint:check`、`npm test`、技能完整性校验与关键断点实看，通过后再逐个合入 `dev`，不把 5 个方向混在单次超大改动里。
