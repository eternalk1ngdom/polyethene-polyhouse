## 2026-11-26 · 闭环 1：日报排行榜新面孔标识、筛选与昨日退榜速览

### 改动范围与关键设计
- **后端纯计算与零迁移集成**：
  - 新增 `TrendPresenceVO`、`TrendDroppedProjectVO`、`TrendPresenceSummaryVO`，并在 `TrendProjectVO`、`TrendReportVO` 末尾以 `@JsonInclude(NON_NULL)` 兼容扩展，保留全部既有构造器，不改写数据库不可变归档 JSON 与 Redis 缓存内容。
  - 新增无状态纯计算器 `TrendPresenceCalculator`（`service/trend/`）：复用 `TrendWindowIdentity` 稳定 `repositoryId` 归并规则，基于前 7 个自然日已发布快照确定性判定 `NEW_TOP`（空降前 5）、`NEW`（新上榜）、`RETURNING`（重回榜单）、`STREAK`（连榜天数与排名变化），并按上期排名升序生成上一已发布日退榜项目列表；无前序历史时返回 `presenceSummary = null`，避免首期全榜误标。
  - `TrendReportService.report(...)` 在返回公开快照前实时调用 `enrichWithPresence(...)`；若历史范围查询失败或单条历史快照损坏，仅记 warn 日志并优雅降级隐藏异动标识，不阻断主日报阅读；`missingInsightIds()` 走基础读取不增加历史查询开销。
- **前端解码与阅读体验扩展**：
  - `trendCodec.ts` 新增 `signedInt`，`trendReport.ts` 兼容解码 `presence` 与 `presenceSummary`（缺省回退 `null`）。
  - `presentation.ts` 新增 `isNewFacePresence` 与 `presenceBadge`；`TrendProjectEntry.vue` 展示 4 类语义徽标与连榜上升 ≥ 3 位的轻量 `↑N` 提示。
  - `TrendView.vue` 在日报抬头补充 `今日新上榜 X 个`，工具栏新增一键切换 **「只看新面孔 (X)」**（URL 参数 `fresh=1`，与语言、分类筛选自然组合并同步带入详情页连续阅读上下文，保留原始官方排名），榜单底部新增默认折叠的原生 `<details>` **「昨日退榜速览」** 区（适配桌面与 `max-width: 620px` 手机断点）。

## 2026-11-27 · 闭环 2：每日自动采集显性状态面板与 7 日风口简报顺路自动生成

### 改动范围与关键设计
- **独立自动简报开关与故障隔离**：
  - 新增 `TrendBriefingProperties`（`polyhouse.trend.briefing.auto-enabled`，环境变量 `POLYHOUSE_TREND_BRIEFING_AUTO_ENABLED`，默认 `false`），注册至 `TrendConfiguration` 与 `application.yml`。
  - `TrendBriefingService.generateForScheduled(anchorDate)`（标注 `@RequireRole(UserRoleEnum.INSIDER)`）复用核心生成与结算逻辑：先检样本硬门槛（`coveredDays >= 3 && radar3ReadyCount >= 5`），再复用 `TrendBriefingLedger` 同指纹零费用防重与 10 元共享月预算红线。
  - `TrendJobRunner` 仅在每日自动任务（`actorId == null`）发布日报成功且自动简报开关启用时，以独立 `try/catch` 顺路触发一次简报生成；简报任何异常或预算不足仅记脱敏日志，绝不影响已发布日报的任务成功状态；屋主手动任务不顺路扣费。
- **发布台显性状态面板与运维清单**：
  - 后端新增 `GET /api/manage/trend/jobs/schedule`（`TrendJobController`，`OWNER` 权限、`Cache-Control: no-store`、实时核验屋主会话）、`TrendScheduleStatusVO` 及 `TrendJobMapper.recent(5)` / `TrendScheduleMapper.byDay(today)` 只读查询；定时关闭时不访问 `014` 调度表，兼容仅迁移 `010～013` 的环境。
  - 前端新增 `TrendScheduleCard.vue` 并接入 `TrendOwnerView.vue` / `useTrendOwner.ts` / `trendAdmin.ts`，显性展示自动日报开关、北京时间计划时间与补偿延迟、自动简报开关、今日受理状态及最近 5 条任务记录（区分 `定时自动` / `屋主手动`）。
  - `docs/operations/github-tech-radar.md` 补充 Render 与 GitHub Variables 一键开启/回退清单（明确实际云端变更与 `015` 迁移须另行授权）。
