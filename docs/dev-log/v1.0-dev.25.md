### 改动与关键决策
- **前端发布台并发治理与状态机修复**（[useTrendOwner.ts](../../polyhouse-web/src/features/trend/useTrendOwner.ts)）：
  - 在 `OwnerSession` 引入 `/api/manage/trend/*` 共享并发排程器（`MAX_MANAGED_CONCURRENCY = 2`），不放宽后端 `30次/分、突发6、并发2` 安全限流；登录初始化改为公开简报并行、3 个管理读接口严格串行（并发=1），为屋主立即手动触发预留实时余量；切换账号/退出登录时中止在途请求并释放等待队列。
  - 修复 `submit()` 在新建 `requestId` 遇 `429 / 400 / 401 / 403` 等确定未被服务端受理的错误时清理 `intent` 与 `sessionStorage`，彻底消除残留「本次更新待确认」与误变「继续同一次更新」；保留网络异常/5xx 及已有旧 `intent` 重放的幂等保护。
  - 补齐任务终态联动刷新（串行刷新费用账本、自动采集状态与公开 7 日简报）。
- **后端性能优化与 017 迁移核验**（[TrendJobStore.java](../../polyhouse/src/main/java/com/polyethene/polyhouse/service/TrendJobStore.java)、[017_trend_ai_cache_tokens.sql](../../polyhouse/sql/017_trend_ai_cache_tokens.sql)）：
