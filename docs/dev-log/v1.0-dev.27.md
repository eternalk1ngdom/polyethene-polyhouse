## 阶段实施与验收（2026-11-27）

### 1. 星潮阅读页纯前端页头（方案 A 晨雾弥散柔光）

- **纯函数元数据层（`polyhouse-web/src/features/trend/presentation.ts`）**：
  - 新增 `buildTrendHeaderMeta(...)` 及类型 `TrendHeaderMeta` / `TrendHeaderWatermark`：直接解析 `YYYY-MM-DD` 文本（无本地时区偏移），输出左侧克制副文（开源日报：`开源日报 · YYYY-MM-DD 期`；近 7 日风向：`近 7 日风向 · YYYY-MM-DD — MM-DD`，跨年完整保留双年份）与右侧斜体水印结构（眉标 `YYYY` / `7D · YYYY` + 月日 `MM.DD`）。
- **页面替换与样式重构（`polyhouse-web/src/views/TrendView.vue`）**：
  - 移除 `startide-tide-atlas.webp` 导入与 `<img>` 标签，改以纯 CSS 多层 `radial-gradient`（左冰蓝晨雾 + 右淡琥珀晨光 + 底部极淡海雾青过渡）叠加对角柔光底与细腻内高光构成 `.cover`；「近 7 日风向」视图通过 `.cover.is-window` 微妙流转柔光方位。
  - 严格克制留白与信息层级，零杂乱细线、零多余图标；右侧绝对定位 `.cover-watermark`（`aria-hidden="true"`、`pointer-events: none`）展示极淡大号 Georgia 斜体日期水印；桌面端高度收紧至 `152px`（较旧横幅 `224px` 提升首屏榜单露出），`@media (max-width: 640px)` 紧凑适配手机端并保持与工具栏的清爽比例。
- **旧资产核查结论**：
  - 全库检索确认：`startide-tide-atlas.webp` 除已移除的 `TrendView.vue` 外，仍被屋主发布台 `TrendOwnerView.vue`（`.masthead`）引用；首页星潮入口卡面使用 `startide-voyage.webp`（`175,754 bytes`）。因此保留 `startide-tide-atlas.webp` 文件不删，零破坏发布台与首页。
