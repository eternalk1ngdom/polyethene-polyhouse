## 单文件复审与批量替换

- 复审上一阶段单文件实现，确认算法仍是有界直接匹配而非 AC 自动机，不能声称大型目录性能已达标。修正异步文件读取与规则编辑共用版本号导致读取失效的问题：选择只保存 File 引用，开始时固定快照并逐个读取，规则/文件变化和取消终止任务，过期读取不能提交 Worker。
- 修正输出字符数量误称 MB；纯算法保留字符保护，独立批处理层按实际 UTF-8 字节限制输入/输出。入口约束为 1～20 个文件，每个 2 MiB、总输入 5 MiB，每项规则最多 200 字符、20 条，单输出 8 MiB、总输出 16 MiB。
- 批处理纯函数校验平面文件名、严格 UTF-8、NUL、BOM/换行，再调用原文单趟替换。任意文件失败整批不产生结果。多文件名加序号防重名覆盖；Worker 内使用现有 fflate 生成 ZIP，单文件继续直接下载。页面显示文件清单、逐文件受限预览、命中次数、取消和下载，文件及规则不进入账号缓存或 HTTP。
- 新增批量/协议模块，补齐文件抽象字段注释、规则边界及测试；沿用现有目录隔离，不改依赖、后端、鉴权或其他工具。README 和注册表同步实际范围。
- 验证：`mvn -q compile -DskipTests`、`npm run build`、`npm run lint:check` 通过；`npm test` 68 项通过，0 失败。测试覆盖重名、BOM、CRLF、空文件、非法编码/二进制、路径及体积限制、Worker 真 ZIP 编解码；浏览器实际双文件处理、切换预览、ZIP 下载并核对两个文件字节及 BOM；375px 无横向溢出。测试输入与下载包已精确清理，没有运行真实数据库测试。

## 小型文件夹处理

- 新增文件夹选择模式，沿用 20 个文件、单个 2 MiB、总输入 5 MiB 的限制；保留所选根目录、子目录和原文件名，始终导出 ZIP，不修改原文件。浏览器不提供空目录，不能出现在结果中；不支持目录选择的浏览器提示改选文件。
- 页面与 Worker 共享路径校验，拒绝绝对路径、穿越、特殊名称、跨根及大小写/Unicode 规范化后冲突，任一文件失败不生成部分结果。仍只处理严格 UTF-8，不静默跳过二进制或其他编码。
- 验证：`mvn -q compile -DskipTests`、`npm run build`、`npm run lint:check` 通过；`npm test` 70 项通过。浏览器选择含嵌套目录的两个测试文件，完成三处替换并下载 ZIP，核对路径、内容和 BOM。未使用真实账号或数据库测试。

## 手动选择输入编码

- 保持 UTF-8 默认，新增整批手动选择 GBK/GB18030 输入；浏览器严格解码，结果统一保存为 UTF-8，页面明确提示检查预览、格式变化及 HTML/XML 内编码声明。不能可靠自动判断编码，误选时也可能出现可解码乱码。
- UTF-8 BOM 在旧编码模式下被明确拒绝；输入含 NUL 或无法按所选编码解码时整批失败；替换结果包含孤立代理项时拒绝导出，避免 UTF-8 编码器静默替换字符。文件与规则不上传，原文件不覆盖。
- 验证：`mvn -q compile -DskipTests`、`npm run build`、`npm run lint:check` 通过；`npm test` 72 项通过。浏览器实际验证 GBK 文件在 UTF-8 模式下报错、选择 GBK 后的替换及下载 UTF-8 字节、切换编码清除旧结果。未连接真实数据库。

## AC 替换内核

- 改用反向构建的 AC 自动机，从右向左记录每个原文位置的最长匹配，再从左向右消费结果；保留先前最左、同位置最长、只匹配原文的行为。每批只编译一次规则，按 UTF-16 代码单元兼容既有语义；每个输入代码单元使用一字节候选缓冲区。
- 验证：`mvn -q compile -DskipTests`、`npm run build`、`npm run lint:check` 通过；`npm test` 75 项通过，包括 3000 组固定随机种子与直接匹配算法对照、重叠及规则快照。浏览器实测 `abc ab abc` 按 `ab→X`、`abc→Y` 得到 `Y X Y`。未连接真实数据库。
- `node benchmarks/poly-replace.mjs`：本机 Node v24.22.1，预热一次并取三次中位数，仅测已编译内核、不含读取与 ZIP；无匹配 1 MiB ASCII 为直接匹配 64.9 ms / AC 9.5 ms，高重叠 256 KiB 为 517.3 ms / 2.3 ms，密集命中 512 KiB 为 28.7 ms / 12.8 ms。数值依设备和文本变化，不能作为浏览器端到端或大规模内存验收。
