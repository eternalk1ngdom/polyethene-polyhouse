## 2026-10-27 首页与整体框架（已完成）

- **首页与外壳：** `App.vue` 统一主要内容、跳过导航和页脚，scoped 样式中的显式全局选择器仅设置基础字体、颜色和盒模型；`HomeView.vue` 实现暖白、深绿、少量杏色的首页，包含标题、工具入口、静态概念插画和项目介绍。插画明确标记概念示意，不接收文件或伪造处理结果。
- **入口与复用：** `toolRegistry.ts` 集中维护工具名称、路由、用途、图标名、状态与计划，首页/导航共用清单；注册表不依赖 UI 组件。`TopNavBar.vue` 提供当前导航标记和账号说明小窗，Enter 打开、Escape/点击外部关闭；没有把缓存 Token 当作已验证身份。
- **路由与状态：** `/` 为首页，`/replace`、`/targetkb` 通过两个已有视图复用 `ToolComingSoon.vue` 显示真实开发状态；未知路径由 `NotFoundView.vue` 提供返回入口。路由更新浏览器标题、恢复后退滚动与工具区锚点；缺少工具页面映射会及早报错。后续新增工具仍需真实页面，不能只靠元数据获得业务能力。
- **入口资源：** `main.ts` 加载现有 Element Plus 样式，组件按需导入；`index.html` 补中文语言、品牌标题和描述，`public/polyhouse.svg` 为本地小屋图标。未增加依赖，未修改 Vite proxy/alias/插件、后端、数据库、认证存储或只读策划书。
- **实际验证：** `mvn -q compile -DskipTests`、前端 `npm run build`、5 项 `node --test tests/auth-session.test.mjs` 通过；本轮 Vue/TS 文件 ESLint 和 Prettier 检查、`git diff --check` 通过。浏览器验证导航与首页卡片、工具页刷新、404 返回、工具区锚点、账号说明 Enter/Escape 和跳过导航；320/390/640/700/约 702/768/960/1280px 八档实际视口均无横向溢出，手机小窗未越界，控制台无警告/错误。验收发现的 Escape 关闭和 320px 滚动条溢出已修复并复测。
- **交付边界：** 本轮账号入口仅显示开发说明，尚无登录弹窗、已登录个人卡片或个人中心；妙替/妙压仅有说明页，算法、上传、处理及云端预设尚未实现。正式部署仍需配置历史路由回退到 `index.html`。截图作为本机交付预览，不将生成产物或个人配置纳入提交；仅本地提交，不推送 GitHub。

## 2026-10-27 注册登录与浏览器会话（已完成）

- **统一请求与契约：** `api/index.ts` 提供独立 Axios 实例、12 秒超时、HTTP/业务码校验及安全 `ApiError`；不传播原始请求、响应或异常链。`api/auth.ts` 接通注册/登录/me，保留原退出/注销请求体与错误类型；公开入口不发送旧 Bearer，只有显式认证请求的 401 才通知会话失效。用户资料运行时检查并投影，大整数必须为字符串；409 注册冲突、错误密码和 403 分别提示，不信任原始错误正文。
- **状态与并发：** `useUserStore.ts` 区分未登录/确认中/已登录/暂不可确认；缓存资料不参与恢复，必须向 `/me` 确认。恢复去重、Token 与递增版本共同阻止旧恢复/退出/登录覆盖新身份；共享缓存提交前再核对，旧清理不能删除另一标签页的新 Token。网络、403 或格式错误保留凭据但不展示未确认身份；禁用/配额不足的存储退化为内存登录并提示。`main.ts` 安装 401 回调，启动、页面重新可见及存储事件触发安全恢复。
- **弹窗与入口：** `AuthDialog.vue` 使用 Element Plus 表单，`utils/authValidation.ts` 提前检查账号、昵称、原始密码及 BCrypt 的 72 字节 UTF-8 边界；确认密码不发送，密码不进入缓存，提交结束/切换/关闭清除密码，提交期间禁用重复操作。注册成功切回登录，不自动建立会话。`TopNavBar.vue` 接入真实登录入口、故障重试和基础已登录菜单（昵称、账号、退出）；个人中心、完整资料卡和账号注销确认留给下一模块。弹层样式通过宿主与 scoped deep 选择器限定，并在矮屏内滚动。
- **自动验证：** `mvn -q compile -DskipTests`、`npm run build`、23 项 `node --test tests/auth-session.test.mjs`、本轮 Vue/TS 的 ESLint/Prettier 及 `git diff --check` 通过。原 5 项会话测试保留并迁移到真实共用请求实例，新增恢复、并发去重/乱序/同 Token 版本、多标签页、故障重试、401/403、响应投影、存储故障和 Unicode 边界；模拟 adapter 的异常覆盖不冒充真实网络验收。未重新运行后端历史 258 项全量测试。
- **真实浏览器验收：** 使用随机 `web_it_` 测试账号，完成注册不自动登录、重复账号 409、连续 6 次密码失败后立即成功、刷新恢复、第二标签页恢复及退出同步、退出后刷新保持匿名。暂停本轮启动的后端后页面提供重试；恢复后端并点击重试，无需重输密码即可恢复；仅删除该夹具的 PC Redis 白名单后，刷新收到 401 并清理旧凭据。关闭再打开弹窗密码为空；320/390/768/1280px 注册弹层无水平溢出，320×640 矮屏可内部滚动。403、实际存储拒绝/配额及畸形响应由客户端自动测试覆盖，未伪称逐项浏览器注入。
- **数据与交付：** 私有预设仅复用，数据库及运行密钥不改动；真实 MySQL 查询确认重复登录/刷新后仍为 10 经验、Lv1、1 硬币且只有一笔日奖励。验收结束精确清理该随机账号及级联奖励流水，残留均为 0，Redis 会话已撤销。README 同步运行和恢复边界；后端源码、数据库结构、Vite 配置、依赖、算法内核和只读策划书均未改动。截图保存在本机交付目录；仅创建本地提交，不推送 GitHub。
