## 2026-10-27 首页与整体框架（已完成）

- **首页与外壳：** `App.vue` 统一主要内容、跳过导航和页脚，scoped 样式中的显式全局选择器仅设置基础字体、颜色和盒模型；`HomeView.vue` 实现暖白、深绿、少量杏色的首页，包含标题、工具入口、静态概念插画和项目介绍。插画明确标记概念示意，不接收文件或伪造处理结果。
- **入口与复用：** `toolRegistry.ts` 集中维护工具名称、路由、用途、图标名、状态与计划，首页/导航共用清单；注册表不依赖 UI 组件。`TopNavBar.vue` 提供当前导航标记和账号说明小窗，Enter 打开、Escape/点击外部关闭；没有把缓存 Token 当作已验证身份。
- **路由与状态：** `/` 为首页，`/replace`、`/targetkb` 通过两个已有视图复用 `ToolComingSoon.vue` 显示真实开发状态；未知路径由 `NotFoundView.vue` 提供返回入口。路由更新浏览器标题、恢复后退滚动与工具区锚点；缺少工具页面映射会及早报错。后续新增工具仍需真实页面，不能只靠元数据获得业务能力。
- **入口资源：** `main.ts` 加载现有 Element Plus 样式，组件按需导入；`index.html` 补中文语言、品牌标题和描述，`public/polyhouse.svg` 为本地小屋图标。未增加依赖，未修改 Vite proxy/alias/插件、后端、数据库、认证存储或只读策划书。
- **实际验证：** `mvn -q compile -DskipTests`、前端 `npm run build`、5 项 `node --test tests/auth-session.test.mjs` 通过；本轮 Vue/TS 文件 ESLint 和 Prettier 检查、`git diff --check` 通过。浏览器验证导航与首页卡片、工具页刷新、404 返回、工具区锚点、账号说明 Enter/Escape 和跳过导航；320/390/640/700/约 702/768/960/1280px 八档实际视口均无横向溢出，手机小窗未越界，控制台无警告/错误。验收发现的 Escape 关闭和 320px 滚动条溢出已修复并复测。
- **交付边界：** 本轮账号入口仅显示开发说明，尚无登录弹窗、已登录个人卡片或个人中心；妙替/妙压仅有说明页，算法、上传、处理及云端预设尚未实现。正式部署仍需配置历史路由回退到 `index.html`。截图作为本机交付预览，不将生成产物或个人配置纳入提交；仅本地提交，不推送 GitHub。
