## 3. 武汉个人主体：从准备到公网试运行

以下针对当前免费、个人学习工具网站作准备，不保证审核结果。最终以湖北管局、接入商及属地网安对实际功能的要求为准；不会为通过备案隐瞒功能或虚构主体。

1. **先核对主体与网站口径。** 腾讯云[湖北管局要求](https://cloud.tencent.com/document/product/243/51714)的“个人备案”页签：负责人须满18周岁；身份证地址非湖北的，需提供要求的当地证明（页面列暂住证、居住证、当地社保卡）；首次/新增每次只允许一个网站。“个人空间/博客”之外的服务内容须说明实际内容。本项目为文字替换/图片体积工具，带受控账号、昵称/头像审核，不能直接包装成纯博客。是否可用拟定名称“聚妙屋”、分类与这些账号功能通过个人备案，尚未得到针对性确认；该页还提示个人主体不可直接变更为企业，未来转商业主体需提前问清迁移方式。
2. **选本人域名与合格的大陆云资源。** 域名需可备案且实名信息与主体符合要求；未选域名/后缀，不默认可备案。主体在湖北不等于服务器必须在武汉；上海等地域与湖北主体是不同概念。腾讯[备案云资源](https://cloud.tencent.com/document/product/243/18908)目前要求大陆轻量包年包月累计至少3个月、备案期间剩余至少1个月、有符合要求的公网IP及非零带宽；一年套餐仍应核对具体 SKU。个人账号可使用本人合格资源直接备案，不需要另买或向别人借备案授权码（个人账号不支持生成此码）。
3. **办理 ICP 备案后再开放公网网站。** 通过接入商填报真实主体、域名、名称、实际服务与材料，完成初审、核验、湖北管局审核。腾讯[备案服务本身免费](https://cloud.tencent.com/document/product/243/45097)，服务器/域名等资源另付费；无需默认购买收费代办。法定材料齐全后的办理时限与接入商初审/补件时间不同，不能保证几天办完。未备案期间不先把实际网站或仅IP入口提供给朋友；真正不对公网提供网站的本机/私网测试应与公网建站区分。
4. **开通后办理公安联网备案。** 纳入开通后30日内申请的准备时间窗，实际以武汉属地要求为准；取得编号后按要求展示链接/标识。武汉公安[本地说明](https://gaj.wuhan.gov.cn/zwgk_12/zcfg/tzgg/202001/t20200108_658853.html)区分交互/非交互网站，旧页面的具体电话和处理周期不直接当当前承诺；当前平台入口从公安机关官方渠道确认。账号、头像上传等需如实申报，由受理机关判断类别。[公安机关对开通后30日内申请的说明](https://ga.sz.gov.cn/ZT/HLWSYSQ/CJWT/content/post_11490792.html)作为流程参考，不代替武汉具体受理答复。
5. **备案后持续维护。** 展示真实 ICP 编号及工信部查询链接；域名、主体、接入商和联系方式保持准确。购买主机、ICP备案通过、公安备案、代码上线是不同状态；备案不是对网站全部功能的安全/内容/经营资质背书。免费测试方向无需现在为了采购而预先注册公司，但不预先断言所有工具服务都必获个人备案。

建议将以下真实内容作为后续咨询草稿（尚未发送，不等于已获认可）：个人开发学习项目，提供浏览器端文本替换和图片体积处理，工具文件不上传；由主办者受控开户，仅少量朋友免费测试；现有昵称/头像先审后发，不提供论坛、聊天或公共文件分享。请接入商确认适用的网站服务分类、名称、备注以及账号/头像功能要求。

## 4. 上线前应复核的法律与运营边界

- **非经营性与经营性。** 当前免费用途按非经营性备案方向准备；依据[现行互联网信息服务管理办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_483f0dd8eb1b4dc5961e4e008bd4a083.html)。若未来收费工具/会员、广告、商城、云文件分享、社区等改变业务，须按具体模式重新核对主体、经营许可及其他要求，不能用一张个人备案包办，也不能把任何广告一概断言为必需 ICP 许可证。当前不扩展这些业务。
- **个人信息与公开资料。** 工具文件本地处理降低服务器持有文件的风险，但账号、昵称、头像、IP/日志仍可能涉及个人信息。上线前核对实际收集项、合法处理依据、清晰告知、公开资料授权、保存期限、查询/更正/删除/注销和必要备份处理；告知应与实际代码及服务器日志一致。已有改密/注销/审核不等于已完成隐私合规验收。依据[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)；不在聊天或 Git 收集朋友身份证，不因主办者备案擅自扩展访客数据采集。
- **内容与知识产权。** 核对旧昵称/头像，保留先审后发及反馈处理入口；测试者使用有权使用的头像、素材，不上传违法或侵权内容。具体法律义务仍按实际服务判断；不以免责声明替代审核/处置。
- **网络安全与日志。** 核对 HTTPS、最小网络暴露、访问控制、补丁、备份恢复和事件处理；[2025年修正、2026年施行的网络安全法](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm)第二十三条要求依规定保留相关网络日志不少于六个月。具体日志范围、权限、容量/轮转、法定留存与个人信息最小必要的协调须形成方案；不等于保存所有用户文件/请求正文，不记录密码或 Token。等级保护适用要求也在恢复 P5 时据实核对，不直接断言个人站免除所有安全义务，亦不默认采购某个等级测评服务。

依据：[非经营性互联网信息服务备案管理办法](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)明确公网域名/IP网站的备案及标识等义务。以上是当前公开规则与本项目的适用分析，不是保证审核通过的法律结论；有疑义时以接入商/主管部门书面口径为准，必要时再咨询专业人士。
