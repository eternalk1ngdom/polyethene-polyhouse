- 用户决定替换既有视觉方向，参考 Dribbble 颜色和画廊布局，保留类 B 站的个人功能组织。新首页采用白底/墨色、大标题、圆角搜索、真实分类及工具封面；个人页重做封面、信息、成长、工具入口和管理布局，公共导航/页脚/弹窗及妙替工作台同步。具体颜色、接口表与行为见[设计记录](../design/frontend-v2.md)。
- `App.vue` 统一语义色；`toolRegistry.ts` 追加类别、更新装饰色；`ToolArtwork.vue` 提供原创代码封面。首页搜索只读本地注册表；Enter 与发现入口使用既有平滑锚点。修复手机装饰重叠和 455px 下昵称被刷新按钮挤成竖排，个人资料小屏改用网格。
- 保留现有 API/store/Worker/纯算法分层，后端、数据库结构、权限、奖励/会话、头像补偿、妙替算法/限制和依赖配置未改动。7 个既有业务接口及头像资源均接入；妙压仍未开放，不新增假能力、社交功能或 3D。
- 在原基线 `4f0fca1` 建立 `codex/backup-ui-v1-20261028`，另建 `codex/ui-v2-dribbble` 开发；`main` 保持原位。Git 忽略的离线 bundle 已校验，并在独立忽略目录克隆/还原全部跟踪文件，`git fsck --full`、HEAD 与干净工作区核对通过；既有工作区文件未混入。切换条件、离线恢复、代码与数据库备份差别见[回滚说明](../operations/frontend-variants.md)。未执行远端推送或发布。
