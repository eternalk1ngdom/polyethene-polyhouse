## 免费隔离链路

在仓库根目录运行：

```powershell
./polyhouse/scripts/Invoke-LocalAuth.ps1 -Action Verify -TrendHttpOnly
```

复用已忽略的本机预设，只连接本机MySQL服务器，创建随机`polyhouse_trend_http_…`库并执行001、010～014；不修改`polyhouse_db`。使用已缓存的`redis:7-alpine`创建资源受限、只绑定127.0.0.1随机端口的临时实例，不启动WSL、不改原Redis、不挂载宿主数据卷。脚本不自动拉镜像，Docker是专项验收环境，不是项目新增运行依赖。

JUnit实际经过HTTP、登录、JWT/Redis会话、权限拦截器、MySQL事务、后台执行线程、AI账本、发布与内容缓存Lua；仅GitHub和AI边界使用假响应。覆盖非屋主拒绝、初始密码限制、角色/凭据撤销、同意图防重及忙时合并、成功发布、解读复用、失败保留旧版、未知费用继续占用。遵守原限流的短`Retry-After`，不放宽过滤器。测试退出删除自身会话/缓存和随机库，脚本finally清理本次容器。

相关三个PowerShell入口/包装测试保存为带BOM的UTF-8，Windows PowerShell 5.1和PowerShell 7均可识别中文；原生空字符串参数也按对应版本处理。已实际在PS5执行免费链路及假Key包装，不需要修改用户执行策略。

## 真实小样本：只在用户本机隐藏输入

前置：官方平台专用Key已准备好，已核对账户为人民币（CNY）计费；免费隔离链路和真实GitHub兼容检查通过。不要把Key发到聊天、写进命令参数、配置文件或截图。

```powershell
./polyhouse/scripts/Invoke-TrendAiLocal.ps1 -Action VerifyLive -CurrencyCny
```

看到隐藏输入提示后再输入Key；环境仅传给本次进程树，退出恢复。程序自动创建临时Redis、本机专属`polyhouse_trend_live_acceptance`库，后端只监听127.0.0.1随机端口；模拟账号密码/JWT随机生成，不使用正式屋主。每日定时关闭，真实源码采集完成后只取至多两个可分析项目进入原任务/AI/预算流程，模型HTTP固定发往官方域名。它不是完整25项目批次的吞吐量验收。

**真实验收月上限0.10元，属于原10元月总预算的一部分。** 费用和未知预留保存在专属库，退出不删库、不清账本。同月固定请求编号，重复运行返回原事实，不自动换号收费；发现旧活动任务或RESERVED/UNKNOWN费用则拒绝启动，须先核对，不能删库重建来重试。出现失败或超时先反馈脱敏状态，勿反复运行。单次等待最多六分钟，超时保留诊断并停止本次执行器。

同月正式启用前，须在发布配置与验收记录中为这0.10元保留额度，正式环境月上限先按**9.90元（`polyhouse.trend.ai.monthly-budget-micros=9900000`）**设置；本轮不修改正式配置。重复验收、手动及自动采集不能在不同数据库各获得完整十元额度。应用账本是保守估算，仍须核对平台实际用量/账单，不等同平台余额硬封顶。

2026 年 11 月另有一次已执行的写作验收。包装入口为 `-Action VerifyLive -CurrencyCny -EditorialSample`，固定选择公开的 `cursor/plugins`。固定榜单行只用于定位项目，元数据与 README 走实际采集器。该入口只允许当月的一次固定任务，与上面的 G4 样本共用同一账本。脱敏结果保存在 `.local-backups/trend-live/editorial-radar-2.json`。复核这次失败请直接读该文件，对照对应请求编号的校验日志；再次运行无法补回被拒正文。[11 月 21 日验收记录](../dev-log/v1.0-dev.15.md#单篇真实验收与正文拒收)
