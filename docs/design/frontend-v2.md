# 前端方案二：工具画廊与个人空间

日期：2026-10-29。状态：已实现、本地验收，未发布。替代旧版视觉方向；工程契约、业务范围和接口保持原有约定。

## 视觉与布局

- 参考 [Dribbble](https://dribbble.com/) 的中性白底、深墨色文字、大标题、圆角搜索与作品画廊组织方式；没有复制其品牌、作品或页面素材。使用 UI/UX Pro Max 的极简布局与 Vue 指南辅助判断。
- 背景 `#ffffff`，正文/主要按钮 `#0d0c22`，说明文字 `#626274`；粉色 `#ea4c89` 只作点缀，文字与键盘焦点用更深的 `#b52b62`。淡紫与蜜桃色用于工具封面/个人封面，米白用于介绍区。
- `App.vue` 集中管理语义色变量与公共控件；页面样式继续 scoped。字体使用系统字体和本机 Georgia，不新增字体、图片网络请求或依赖。
- 首页改为导航 → 居中介绍/搜索 → 分类与工具画廊 → 品牌介绍。搜索即时筛选本地注册表，Enter/箭头定位结果区；无结果可重置。只展示实际登记的两个工具，开放状态明确区分。
- `ToolArtwork.vue` 是原创 CSS 排版和 Element Plus 图标构成的装饰封面，不是算法处理结果。小屏隐藏次要装饰、给标题与操作区留白；无需维护重复的图片素材。
- 个人区保留类 B 站的头像小窗、个人封面、身份/等级/经验/硬币、资料与管理组织方式；不新增粉丝、动态、关注、收藏等未实现业务。个人页分区使用真实锚点，不显示虚构选中页签。
- 妙替工作台、登录/注册、头像裁剪、注销确认、工具介绍和 404 同步中性色。手机个人资料使用两列网格，刷新按钮另起一行，避免中间宽度挤压昵称。

## 接口与功能核对表

2026-10-30 补充：下表保留方案二改版时的接口与验收快照。公共注册已在 P2 关闭，P1 改密、P2 开户、P3 管理及 P4 审核已后续交付；旧头像上传地址已关闭，当前接口以 [README](../../README.md) 和[资料审核说明](../operations/profile-moderation.md)为准，不沿用下表的立即发布契约。

现有 Controller 共 7 个业务 HTTP 入口，全部复用原有 `api/`、会话及成长 store；本轮不另建身份缓存或请求客户端。

| 入口 | 新版调用位置/行为 | 本轮验证 |
| --- | --- | --- |
| `POST /api/auth/register` | 注册弹窗；成功后回到登录，不伪造已登录 | 临时普通账号实际注册成功 |
| `POST /api/auth/login` | 登录弹窗；维持 PC 终端契约 | 登录、退出后重登成功 |
| `GET /api/auth/me` | 启动恢复、个人页、刷新资料 | 页面刷新恢复最新资料成功 |
| `GET /api/auth/growth` | 头像小窗与个人成长面板 | 实际显示 Lv1/10 经验/1 硬币、33% 及今日奖励，重复刷新/重登未增加 |
| `POST /api/auth/avatar` | 个人页选择、缩放裁剪与保存 | 测试 PNG 裁剪保存后显示成功，剩余 4 次 |
| `POST /api/auth/logout` | 小窗与账号管理共用退出方法 | 退出成功并显示未登录状态；不清其他终端 |
| `POST /api/auth/deregister` | 知悉影响 + 输入确认词双重确认 | 少一项仍不可提交，普通临时账号实际软注销成功 |
| `GET /api/media/avatars/{32位随机名}.jpg` | 共享头像展示；不是新增 Controller 方法 | 保存后的实际图片正常加载 |

OWNER 普通注销仍被原有前后端保护；本轮不操作真实屋主。角色不由等级、头像或浏览器缓存决定。大整数仍用十进制字符串传递；奖励门槛、日期和到账依据仍来自服务端。

妙替没有后端处理接口：文件 → 原有页面任务管理 → Worker → 纯 TS 算法/ZIP → 预览/下载。原有文件数、体积、编码、路径校验、取消与过期回调隔离保持不变；实际 `.py` 输入得到三处全文替换与正确预览。妙压继续为筹备页；不增加假上传、假进度或未存在的 API。
